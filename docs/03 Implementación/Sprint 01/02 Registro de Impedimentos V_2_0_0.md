## 4. Procedimiento para nuevos registros

1. Describir qué bloquea o retrasa el trabajo.
2. Explicar el impacto sobre una historia, una entrega o el cronograma.
3. Asignar prioridad según impacto y urgencia.
4. Registrar quién lo reportó y quién dará seguimiento.
5. Definir una fecha objetivo de resolución realista.
6. Actualizar el estado mientras se trabaja en la solución.
7. Registrar la fecha y la acción aplicada al resolverlo.
8. Mantener el registro alineado con Jira.
