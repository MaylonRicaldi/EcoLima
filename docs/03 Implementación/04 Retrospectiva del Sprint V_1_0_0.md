# Retrospectiva del Sprint

**Nombre del Proyecto:** EcoLima  
**Líder del Proyecto:** Diego Marlon Quispe Povis

## ¿Qué aprendimos?

Durante el Sprint 1, correspondiente al desarrollo del primer Producto Mínimo Viable (PMV), el equipo aprendió a utilizar Jira como herramienta para organizar y realizar el seguimiento de las actividades del proyecto. Este Sprint se desarrolló desde el 14 de septiembre hasta el 4 de octubre de 2026.

Asimismo, se comprendió la importancia de distribuir las tareas, definir responsabilidades y mantener una coordinación adecuada entre los integrantes para cumplir con los objetivos establecidos.

Actualmente, el equipo se encuentra desarrollando el Sprint 2, en el cual se busca aplicar lo aprendido durante el primer Sprint y mejorar la organización y seguimiento de las actividades.

## ¿Qué estamos haciendo bien?

El equipo logró organizarse adecuadamente durante el desarrollo del Sprint, manteniendo las actividades registradas y realizando seguimiento de las historias de usuario en Jira.

## ¿Qué podemos hacer mejor?

### Personas

Mejorar la distribución de las tareas entre los integrantes del equipo, considerando las actividades pendientes y las responsabilidades de cada integrante.

### Relaciones

Mejorar la comunicación entre los integrantes del equipo para mantener una coordinación más clara durante el desarrollo de las actividades.

### Procesos

Organizar y distribuir las tareas de manera más clara al inicio del Sprint, de modo que cada integrante conozca sus responsabilidades y pueda realizar un mejor seguimiento de sus actividades.

### Herramientas

Continuar utilizando Jira para registrar, organizar y realizar el seguimiento de las Historias de Usuario y actividades del proyecto, aprovechando mejor sus funcionalidades.

## Acciones a realizar

Para el siguiente Sprint, el equipo acordó mejorar la distribución de las tareas entre los integrantes y fortalecer la comunicación durante el desarrollo de las actividades.

Las principales acciones serán:

- Distribuir las tareas de manera más clara al inicio del Sprint.
- Definir las responsabilidades de cada integrante.
- Mejorar la comunicación y coordinación del equipo.
- Continuar utilizando Jira para realizar el seguimiento de las actividades.
