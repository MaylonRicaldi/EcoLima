### 1.3 Mapa de Empatía - Conductor (Perfil Crítico)

> **Dice:** "No entiendo el mapa, solo quiero saber dónde entregar primero."
> **Piensa:** "Si me mandan por Ciudades Satélite de noche es peligroso."
> **Siente:** Presión por penalidades de tardanza, fatiga por 8h conducción, orgullo por ahorro de combustible.
> **Hace:** Usa WhatsApp para reportar tráfico, pide referencias por teléfono, evita calles de tierra con camioneta.

**Implicación de diseño:** Modo Conductor con 3 botones máximos, lista ordenada de entregas, botón SOS/Reportar incidencia, navegación integrada, texto "Has ahorrado S/ XX hoy".

## 2. Historias de Uso Resumidas (Mapa Sintético de Interacciones por Perfil)

### Administrador
*   Como Administrador quiero registrar un vehículo con su factor de emisión y restricción MTC para que el algoritmo excluya automáticamente vehículos no habilitados.
*   Como Administrador quiero configurar parámetros globales (costo diésel S/17.50, mant S/1.20/km, factor CO₂) para que los reportes TCO sean precisos.
*   Como Administrador quiero generar el reporte mensual PDF con huella CO₂ y plan de compensación (árboles Huáscar) para presentar a gerencia y auditor.
*   Como Administrador quiero gestionar conductores (DNI, licencia, disponibilidad, punto de partida Villa El Salvador) respetando Ley 30224.

### Operador / Técnico
*   Como Operador quiero registrar 50 pedidos con direcciones informales y puntos de referencia para alimentar la optimización del día siguiente.
*   Como Operador quiero generar rutas optimizadas para 150 pedidos/15 vehículos y visualizar el trazado con congestión verde/amarillo/rojo.
*   Como Operador quiero re-optimizar en ≤30s ante un accidente en Av. Próceres reportado por SIMAT/Waze.
*   Como Operador quiero asignar manualmente un pedido express a la ruta con menor desvío de CO₂.

### Conductor (Modo Conductor)
*   Como Conductor quiero ver solo mi ruta del día con lista ordenada de entregas, ETA y botón "Iniciar Navegación" para no distraerme conduciendo.
*   Como Conductor quiero reportar en un tap un incidente (tráfico, avería, zona insegura) para que el Operador re-optimice.
*   Como Conductor quiero ver mi indicador "Has ahorrado S/ XX y evitado XX kg CO₂ hoy" en lenguaje simple.
*   Como Conductor quiero recibir alerta si mi jornada supera 4h continuas para tomar descanso obligatorio de 1h.

### Auditor Externo
*   Como Auditor quiero acceder en solo lectura a logs de auditoría, reportes TCO y evidencias de cálculo ISO 14083 sin poder modificar datos operativos.
*   Como Auditor quiero exportar logs filtrados por rango de fechas y usuario para trazabilidad.

### Cliente (Bodeguero)
*   Como Cliente quiero registrar mi horario preferido (Ej. 07:00-09:00) y referencia ("frente al paradero") para que mis entregas respeten mi ventana.
*   Como Cliente quiero recibir notificación por WhatsApp/SMS con ETA actualizado si la ruta se re-optimiza.

## 3. Matriz de Control de Acceso (RBAC / ABAC)

### 3.1 Modelo: RBAC con extensión ABAC para restricciones contextuales

*   **RBAC base:** 4 roles canónicos (Administrador, Operador/Técnico, Usuario Final/Cliente, Auditor Externo) + rol Conductor (sub-perfil de Usuario Final con permisos operativos móviles).
*   **ABAC:** Atributos evaluados en tiempo de ejecución: `horario_operativo (05:00-22:00)`, `zona_distrital`, `estado_conductor (jornada)`, `placa_restricción_MTC`, `sensibilidad_dato (Ley 29733)`.

### 3.2 Matriz CRUD (C=Crear, R=Lectura, U=Actualizar, D=Eliminación Lógica, X=Eliminación Física, - = Sin Acceso)

| Módulo / Capacidad | Rol: Administrador | Rol: Operador / Técnico | Rol: Conductor | Rol: Usuario Final (Cliente) | Rol: Auditor Externo |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Configuración de Parámetros** (costos diésel/GNV, factores emisión, umbrales, distritos) | **CRUD** | **R** (solo lectura) | **-** | **-** | **R** (solo lectura) |
| **Gestión de Flota** (vehículos, TCO) | **CRUD** | **R + U** (actualizar estado operativo: disponible/en ruta/avería) | **R** (solo su vehículo asignado) | **-** | **R** |
| **Gestión de Pedidos** | **CRUD** | **CRUD** | **R** (pedidos de su ruta) + **U** (marcar entregado/fallido) | **C/R** (propios pedidos, preferencias) | **R** |
| **Gestión de Conductores** (DNI, licencia, jornada) | **CRUD** | **R** | **R** (propio perfil) + **U** (disponibilidad) | **-** | **R** |
| **Módulo de Clientes / Preferencias** | **CRUD** | **CRUD** | **R** (datos de entrega de su ruta) | **C/R/U** (propias preferencias) | **R** (anonimizado si aplica) |
| **Generación y Re-optimización de Rutas** | **C/R** | **C/R/U** (operación diaria) | **R** (ruta asignada) | **R** (ETA de su pedido) | **R** |
| **Visualización de Rutas en Mapa** | **R** | **R** | **R** (ruta propia) | **R** (tracking de su pedido) | **R** |
| **Dashboard de Indicadores** | **R** (completo) | **R** (operativo) | **R** (modo simplificado: ahorro personal) | **-** | **R** (indicadores agregados) |
| **Reportes de Sostenibilidad (PDF)** | **R** (generar/exportar) | **R** (generar/exportar operativo) | **-** | **-** | **R** (generar/exportar auditoría) |
| **Plan de Compensación de Carbono** | **CRUD** (calcular y proponer) | **R** | **-** | **-** | **R** |
| **Registro de Datos Transaccionales** (entregas, estados) | **CRUD** | **CRUD** | **C/R/U** (crear evento de entrega) | **C/R** (confirmar recepción) | **R** |
| **Depuración / Eliminación Física** | **X** (solo con doble confirmación y backup) | **-** | **-** | **-** | **-** |
| **Exportación de Logs de Auditoría** | **R** (lectura) | **-** | **-** | **-** | **R** (Solo Lectura, sin exportación masiva sensible) |
| **Gestión de Usuarios y Roles (RBAC)** | **CRUD** | **-** | **-** | **-** | **-** |
| **Reporte de Incidentes (tráfico/seguridad)** | **R** | **C/R** | **C/R** | **C** (incidencia de entrega) | **R** |

### 3.3 Reglas ABAC Complementarias (Evaluadas en Middleware)

| Regla ABAC | Descripción |
| :--- | :--- |
| **ABAC-01 Jornada** | Un Conductor no puede ser asignado a ruta si `horas_conducción_continua ≥ 4h` sin descanso o `jornada_total ≥ 8h` (Ley 30224). El sistema bloquea asignación y sugiere reemplazo. |
| **ABAC-02 Restricción MTC** | Vehículo con `último_dígito_placa = restringido_hoy` (D.S. 033-2012-MTC) no es elegible para optimización en ese día, aunque el rol tenga permiso. |
| **ABAC-03 Horario Operativo** | Operaciones de generación de rutas solo permitidas en ventana 05:00-22:00; fuera de ventana solo lectura (RNF-003). |
| **ABAC-04 Datos Sensibles** | DNI, licencia y contacto de conductores solo visibles para Administrador y Operador asignado; Conductor ve solo su propio registro (Ley 29733, principio mínima exposición). |
| **ABAC-05 Zona Segura** | Si la ruta propuesta atraviesa zona marcada como alta incidencia (PNP) en horario nocturno (18:00-06:00), el sistema exige confirmación del Operador (opt-in). |

### 3.4 Principios de Seguridad Aplicados

*   **Mínimo privilegio:** Cada rol posee solo los permisos estrictamente necesarios.
*   **Defensa en profundidad:** Middleware de autorización en API Gateway + validación a nivel servicio + RLS (Row Level Security) en PostgreSQL para filtrado por `conductor_id / cliente_id`.
*   **Auditoría:** Toda operación CUD registra `usuario_id, timestamp, IP, payload hash` en tabla `auditoria_logs` inmutable (append-only), conforme a RNF-002 y Ley 29733.
*   **Autenticación:** JWT con expiración 30min, refresh token rotativo, bloqueo por 3 intentos fallidos/15min (RN-001).
